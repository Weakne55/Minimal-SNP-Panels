# Организация репозитория

- `run_pipeline.sh`, `src/minsnp/`, `stages/`, `config/`, `inputs/`, `envs/` — **новый основной пайплайн**.
- `tests/` — тесты текущего пайплайна. `pytest` запускает только их.
- `data/metadata/` — метаданные белух и белых медведей; `data/full_wgs_20261022/` — исходные FASTQ.
- `results/` — ранее полученные и будущие результаты. Старые результаты не пересчитываются при миграции.
- `literature/` — рабочий обзор литературы; `benchmarks/` — измерения производительности.
- `genome_reference_setup/`, `full_wgs_setup/` — вспомогательные утилиты, временно оставлены на старых путях.
- `metadata/` — прежний каталог источников метаданных, пока без переноса во избежание поломки путей.
- `docs/` — документация действующего проекта; `legacy/old_pipeline_20261030/` — прежний WGS-пайплайн, его конфигурации и исторические файлы.

## Граница миграции

Никакие FASTQ, BAM, gVCF, VCF, референсные FASTA, данные литературы и каталоги результатов не переносились и не удалялись.
Отладка вычислений нового FASTQ → VCF конвейера выполняется **после** переноса на отдельном `run-id`.
