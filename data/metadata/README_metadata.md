**Основной файл:** [`WGS_final.xlsx`](WGS_final.xlsx)  
**Назначение:** инвентаризация опубликованных образцов, SRA runs, географии, предполагаемых популяционных групп и технических характеристик секвенирования.

**Всего:** 255 строк об образцах, 255 различных BioSample IDs и 410 различных SRA runs (121 белухи, 289 медведи).  

## Характеристика WGS

| Показатель | Белуха | Белый медведь |
|---|---:|---:|
| Образцов в таблице | 109 | 146 |
| Записей `data_type=WGS` | 109 | 144 |
| SRA runs | 121 | 289 |
| Образцов с несколькими runs | 4 | 39 |
| Покрытие `coverage_x`, минимум | 10,06× | 0,56× |
| Покрытие `coverage_x`, медиана | 19,21× | 6,00× |
| Покрытие `coverage_x`, максимум | 117,43× | 176,20× |
| Покрытие менее 10× | 0 | 97 |
| Записей без `geographic_population` | 6 | 12 |
| Записей без `sex` | 12 | 20 |

`coverage_x` имеет **разную методику расчёта** (`coverage_basis`): оценки по сырым базам SRA/ENA, опубликованное покрытие и последующие оценки по картированию. Показатели не следует сравнивать как однородные измерения без дополнительной проверки. У медведей 97 записей ниже 10×, поэтому параметры genotype QC и пригодность к анализу структуры требуют отдельной оценки. Запись `reference_WGS_review` относится к PacBio SMRT/SINGLE и не является обычным Illumina paired-end WGS.

## Основные поля

| Поле | Значение |
|---|---|
| `biosample` | Идентификатор BioSample (удобный технический ключ до разрешения дубликатов) |
| `publication_sample_id` / `animal_id_in_paper` | Идентификаторы из публикаций (второе поле есть только у белух) |
| `bioproject`, `sra_runs` | Проект и SRA accession; несколько runs разделены `;` |
| `study`, `doi` | Публикация и DOI |
| `collection_*`, `geographic_population` | Место сбора и географическая группировка |
| `published_geographic_group`, `published_genetic_population` | Опубликованные группы; последнее поле есть только на листе белух |
| `data_type`, `platforms`, `library_layouts` | Тип данных и параметры секвенирования |
| `sequenced_gb`, `sra_size_gib`, `fastq_size_gib` | Объём последовательностей и предполагаемые размеры файлов |
| `coverage_x`, `coverage_basis` | Указанное покрытие и способ его оценки |

## Как использовать в пайплайне

1. Отобрать нужный вид и пригодные WGS записи; исключить или отдельно проверить спорные `data_type` и дублированных животных.
2. Развернуть `sra_runs` в таблицу **один run на строку**, сохранив связь с BioSample и биологическим животным.
3. Указать реальные пути к локальным FASTQ в `inputs/fastq.tsv`: `sample_id`, `species`, `run_id`, `library`, `fastq_r1`, `fastq_r2`. Текущая Excel-таблица содержит accession, **но не локальные пути к FASTQ**.
4. После QC и анализа структуры сохранить отдельно `population_labels.tsv` (`sample_id`, `population`). 

Существующие FASTQ и результаты WGS хранятся в `data/wgs/` и `results/` соответственно
